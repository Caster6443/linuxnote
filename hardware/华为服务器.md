
# 安装dimm顺序

DIMM 全称是 **Dual In-line Memory Module**（双列直插式内存模块），也就是常说的**内存条**。它是安装在计算机主板内存插槽上的硬件，用于临时存储CPU正在处理的数据。

### 安装扩容评估工具和扩容工具的方法

支持通过在线和离线两种方式安装扩容评估工具和扩容工具。

- 扩容评估工具仅适用于华为工程师、渠道工程师和产品用户，其他用户无下载和安装权限。
- 扩容工具仅适用于华为工程师和渠道工程师，其他用户无下载和安装权限。

- 在线安装
    1. 登录SmartKit。
    2. 选择“首页 > 存储 > 扩容 > 更多”。
        系统弹出“扩容”场景下的所有功能。
    3. 单击下载按钮，自动下载并安装扩容评估工具和扩容工具。
- 离线安装
    1. 登录华为企业业务网[https://support.huawei.com/enterprise/zh/index.html](https://support.huawei.com/enterprise/zh/index.html)。
    2. 依次选择工具专区 > SmartKit。
    3. 选择最新版本的SmartKit，进入软件下载界面。
    4. 下载文件名为“SmartKit_XX.X.X_Tool_Inspection.zip”的扩容评估工具安装包，以及文件名为“SmartKit_XX.X.X_Tool_expansion.zip”的扩容工具安装包。
    5. 登录SmartKit，单击“功能管理”。
    6. 单击“导入”，选择获取的扩容评估工具或扩容工具。

## 步骤：两台 Dorado 6800 V6 使用 SmartKit 扩容硬盘

> 先对 `MIT_YMS_ST1` 执行；完成并通过步骤 9 的验证后，再对 `MIT_YMS_ST2` 执行；两台不得同时操作。

**步骤1 打开 SmartKit 软件。**

**步骤2 将需要扩容的存储设备添加到 SmartKit。**

1. 在 SmartKit 主界面上单击“设备列表”页签，选择“添加”，系统弹出添加设备对话框。
2. 在“基本信息”中选择“指定IP地址（指定设备管理IP地址进行添加）”，输入以下管理 IP，单击“下一步”：
    - OceanStor Dorado 6800 V6（`MIT_YMS_ST1`）：`10.254.17.116`，备用 `10.254.17.117`
    - OceanStor Dorado 6800 V6（`MIT_YMS_ST2`）：`10.254.17.118`，备用 `10.254.17.119`
3. 在“登录信息”中输入超级管理员用户名 `admin` 及密码（密码现场向客户索取，不写入本方案），单击“完成”。

> 首次添加会出现“连接不受信任”或“注册并继续连接”提示，确认后继续。

**步骤3 在 SmartKit 主界面上依次选择“首页 > 扩容 > 扩容硬盘、硬盘框、硬盘柜”，进入对应页面。**

**步骤4 选择设备。** 单击“选择设备”，在对话框中选中 **`MIT_YMS_ST1`**（OceanStor Dorado 6800 V6，10.254.17.116），设置任务结果保存路径，单击“确定”。

**步骤5 安全操作指引。** 单击“安全操作指引”，确认界面列出的扩容前置条件已准备完毕，全部勾选后单击“确认”。

**步骤6 评估扩容方案。**

1. 单击“扩容评估”，进入“扩容配置”页签。
[Open: Pasted image 20261028172701.png](_resources/%E5%8D%8E%E4%B8%BA%E6%9C%8D%E5%8A%A1%E5%99%A8/53672a2373e2c1a965100ea000492ba0_MD5.jpg)
![](_resources/%E5%8D%8E%E4%B8%BA%E6%9C%8D%E5%8A%A1%E5%99%A8/53672a2373e2c1a965100ea000492ba0_MD5.jpg)
2. 在“扩容场景”中选择“扩容硬盘、硬盘框、硬盘柜”。
3. 本次不新增接口卡或硬盘框，部件编码栏留空。
4. 单击“添加扩容新硬件信息及存储空间扩容方式”。
5. 在配置列表中填写：

|参数|填写值|
|---|---|
|存储空间扩容方式|在 CTE0 上扩容存储池（ID:2）—— NAS 池|
|硬盘BOM|`02355XJV`|
|硬盘类型 / 单个硬盘物理容量 / 容量单位|由 BOM 自动带出，核对为 NVMe SSD / 1.92TB / TB|
|硬盘数量|`6`|

6. 单击“下一步”，阅读提示信息后单击“确定”，进入“执行扩容评估”页签。
7. 评估完成后，单击“打开结果目录”获取评估报告 zip，或单击“查看报告”直接查看。
8. 单击“完成”，结束评估。

> 若报告中存在“不通过”项，须按修复建议处理后重新评估，不得跳过。

**步骤7 按扩容向导实施扩容。**

1. 单击“扩容”，系统弹框提示选择需要扩容的对象。
    
2. 选择“扩容硬盘”。
    
3. 核对到货硬盘：BOM 为 `02355XJV`，型号为 1.92TB NVMe SSD，本台（`MIT_YMS_ST1`）为 6 块。
    
4. 按机柜和硬盘框位置插入硬盘（**U 位从机柜底部往上数，最下面是 1U**）：
    
    **机柜 E12（`MIT_YMS_ST1`，SN 2102354JLT10P2100002）**
    

|硬盘框|机柜 U 位|插入数量|槽位|
|---|---|---|---|
|DAE000|3U–4U|3 块|任一空闲槽位|
|DAE020|6U–7U|3 块|任一空闲槽位|

- 当前每个硬盘框均有 **26–35 号共 10 个空槽位**，可任选 3 个。
- 3 块硬盘在同一个硬盘框内相邻安装，不要分散。
- 可按槽位号从大到小依次插入（如 35、34、33），便于后续记录和盘点。

5. 插盘操作（指导书 6.2.2）： 
- 佩戴防静电腕带、防静电手套，穿防静电服； 
- 将硬盘从防静电包装袋中取出，把硬盘上的**拉手完全打开（拉到最大角度）**，否则无法完全插入； 
- 对准接口后**均匀用力**插入空槽位，避免用力过大损坏接口； 
- 插到底后合上拉手； 
- 插入后如需拔出，至少等待 1 分钟以上，避免损坏硬盘。

6. **确认新盘已被识别**：在 DeviceManager 或 SmartKit 界面确认新增 6 块硬盘均已识别，健康状态为 Normal、运行状态为 Online，无告警。
7. 勾选“确认检查完成”，单击“确认”，系统开始执行扩容。

**步骤8 扩容后巡检。**

1. 单击“扩容后巡检”，进入巡检工具向导界面。
2. 在检查项列表中选中需要检查的项。
3. 单击“下一步”，开始执行巡检。
4. 单击“完成”结束巡检；“查看报告”可打开 `.html` 格式的巡检结果。

**步骤9 扩容结果验证与记录。**

|检查项|判据|
|---|---|
|新增硬盘状态|6 块均为 Normal / Online，无告警|
|NAS 存储池容量|总容量与可用容量已增加，增量与 6×1.92TB 预期基本一致|
|双活状态|双活域及所有 pair 运行状态为 **Normal**、同步状态为 **All Synced**，无 Interrupted / Consistent / Suspended|
|告警|无新增严重、重要告警|
|记录归档|记录插入的硬盘框、槽位号、硬盘 SN、扩容前后容量，随巡检报告一并归档|

> 上述全部通过后，方可对 **`MIT_YMS_ST2`**（OceanStor Dorado 6800 V6，10.254.17.118，机柜 E13，SN 2102354JLT10P2100001）重复步骤 4–9；E13 的两个硬盘框位置同样是 DAE000 在 3U–4U、DAE020 在 6U–7U，各插 3 块。




## 使用SmartKit扩容存储池

本节承接前面的硬盘安装步骤：本台新增的6块硬盘已安装并识别正常。继续使用已打开的 SmartKit，无须重新添加设备。先完成 E12 的第一台存储扩池及验证，再操作 E13 的第二台；不要同时操作两台。

**步骤1 进入存储池扩容工具，选择第一台存储。**

1. 返回 SmartKit 首页，选择“扩容 > 更多 > 扩容硬盘域/存储池/性能层”。
2. 单击“选择设备”，选择 **`MIT_YMS_ST1`**（现场 DeviceManager 显示为 `MIT_YMS_ST1(E12)`），核对管理 IP 为 **`10.254.17.116`**、设备 SN 为 **`2102354JLT10P2100002`**。
3. 设置任务结果保存路径，例如在现场操作电脑建立 `楚兴扩容结果/MIT_YMS_ST1/存储池扩容` 文件夹，单击“确定”。第二台设备的结果另存，避免混淆。

**步骤2 配置本次存储池扩容参数。**

项目已有扩容评估报告，前期选型和方案评估不在本节重新展开。这里按指导书15.1.1.2配置当前扩池工具需要的参数：工具会按照评估步骤设置的硬盘类型及数量执行扩池，不能仅打开旧报告就认为当前工具已加载参数。

1. 单击“扩容评估”，打开“扩容评估向导”。
2. 在“扩容场景”中选择 **“扩容硬盘域/存储池”**。
3. 单击“添加扩容新硬件信息及存储空间扩容方式”，按下表填写。

![](_resources/%E5%8D%8E%E4%B8%BA%E6%9C%8D%E5%8A%A1%E5%99%A8/bac1e2d94a4f3b29e5784931a54b6daa_MD5.jpg)

上图是指导书示例，不是本项目已经填好的配置。图中的 `DAE010` 不照抄，“自定义”和空白参数按以下实际值填写。

| 界面参数 | 本次具体填写内容 |
|---|---|
| 扩容场景 | 扩容硬盘域/存储池 |
| 存储空间扩容方式 | **在 CTE0 上扩容存储池（ID:2）**，对应现有 **NAS** 存储池；不要选择 SAN 池或新建池 |
| 硬盘框ID | **仅框级冗余场景需要选择**。如界面显示此参数，按下方两行配置分别选择 DAE000、DAE020；如不显示，不必另找入口填写 |
| 硬盘BOM | **`02355XJV`**，本次新增硬盘的物料编码；不要填写现有盘的 BOM |
| 硬盘类型 | 选择 BOM 后由工具自动带出，核对为本次新增的 **NVMe SSD**。按工具实际枚举名称选择，不选 SAS HDD、NL-SAS 或 SCM；是否带 SED 标记以到货物料为准 |
| 单个硬盘物理容量 | **`1.92`**，表示单块盘容量，不填6块合计容量 |
| 容量单位 | **`TB`** |
| 硬盘数量 | 按下方配置填写：显示硬盘框ID时每行 **3**，不显示时一行 **6**；每台合计 **6**，不要填写两台合计12 |
| 操作 | “删除”用于移除误加的配置行；确认无重复行后再继续 |

如果界面显示“硬盘框ID”，添加两行，具体如下：

| 存储空间扩容方式 | 硬盘框ID | 硬盘BOM | 硬盘类型 | 单个硬盘物理容量 | 容量单位 | 硬盘数量 |
|---|---|---|---|---|---|---|
| 在 CTE0 上扩容存储池（ID:2） | DAE000 | 02355XJV | BOM自动带出的NVMe SSD类型 | 1.92 | TB | 3 |
| 在 CTE0 上扩容存储池（ID:2） | DAE020 | 02355XJV | BOM自动带出的NVMe SSD类型 | 1.92 | TB | 3 |

如果界面不显示“硬盘框ID”，相同 BOM、类型和容量合并为一行，硬盘数量填 **6**。两种填法择其一，不能既保留数量6的汇总行，又添加两个数量3的明细行。

> BOM 在工具列表中时，类型、容量及单位会自动带出，仍需核对。若列表没有该 BOM，先核对输入和到货标签；确认编码无误后，按工具提示手动填写类型、容量及单位，不要随意选择相近 BOM 代替。界面参数与本节规划不符时，先停止核对，不要直接提交。

**步骤3 完成当前工具的评估环节。**

1. 核对本次配置为：**MIT_YMS_ST1、NAS池ID 2、1.92TB NVMe SSD、合计6块**。
2. 单击“下一步”，进入“执行扩容评估”页签，等待结束。
3. 单击“查看报告”查看本次结果；单击“打开结果目录”保存报告。报告按第一台设备目录归档，保留项目已有的前期评估报告。
4. 检查不通过时，按报告建议处理后重新评估；仍不通过则停止本台后续操作，联系华为工程师处理。
5. 评估通过后单击“完成”，返回存储池扩容工具页面。

**步骤4 打开“扩容存储池向导”。**

1. 单击“扩容”，在弹出的界面选择 **“扩容存储池”**。
2. 阅读扩容注意事项，确认当前操作对象仍为 **MIT_YMS_ST1（10.254.17.116）**，目标是现有 **NAS池（ID:2）**，新增数量为 **6块**。
3. 确认已完成界面列出的操作后，勾选“我已完成上述注意事项的确认，并了解此操作带来的后果。”，单击“下一步”。

**步骤5 扩容前检查并执行扩池。**

1. 在“扩容前检查”页面等待工具自动检查。全部检查项通过后，单击“下一步”，进入“执行扩容存储池”页面。
2. 若检查不通过，先处理失败项并重新检测，不跳过检查继续执行。
3. 等待工具执行扩容。工具按照前面配置的硬盘类型和数量，将新增容量扩入目标池；执行期间不要对设备做其他变更，也不要拔出新增硬盘。
4. 若执行失败，保存失败界面及任务结果，按工具提示排查；未确认失败原因和已执行到哪一步前，不要盲目重复提交，也不要直接拔盘作为回退。
5. 工具显示扩容存储池完成后，单击“下一步”，进入“完成”页面，再单击“完成”。

**步骤6 扩容后巡检与结果验证。**

1. 单击“扩容后巡检”，进入巡检向导；保留工具默认勾选的检查项，确认覆盖设备健康、硬盘、存储池和告警等相关检查后，单击“下一步”。
2. 等待巡检结束，单击“查看报告”检查结果，通过“打开结果目录”保存HTML报告及压缩包，单击“完成”。新增异常须处理确认后再进入第二台操作。
3. 登录第一台 DeviceManager（管理 IP：**10.254.17.116**），进入 **“系统 > 存储池”**，检查名称为 **NAS** 的存储池：健康状态“正常”、运行状态“在线”，总容量相较本次操作前增加。
4. 记录NAS池扩容前后总容量和未使用容量，并截图。**6×1.92TB＝11.52TB是新增硬盘原始容量，不能直接当作存储池可用容量增量**；验收以工具结果及存储池实际容量为准，未使用容量还会受期间业务写入影响。
