### 安装扩容评估工具和扩容工具的方法

支持通过在线和离线两种方式安装扩容评估工具和扩容工具。

- 扩容评估工具仅适用于华为工程师、渠道工程师和产品用户，其他用户无下载和安装权限。
- 扩容工具仅适用于华为工程师和渠道工程师，其他用户无下载和安装权限。

- 在线安装
    1. 登录SmartKit。
    2. 选择“首页 > 存储 > 扩容 > 更多”。
        系统弹出“扩容”场景下的所有功能。
    3. 单击下载按钮，自动下载并安装扩容评估工具和扩容工具。
- 离线安装
    1. 登录华为企业业务网[https://support.huawei.com/enterprise/zh/index.html](https://support.huawei.com/enterprise/zh/index.html)。
    2. 依次选择工具专区 > SmartKit。
    3. 选择最新版本的SmartKit，进入软件下载界面。
    4. 下载文件名为“SmartKit_XX.X.X_Tool_Inspection.zip”的扩容评估工具安装包，以及文件名为“SmartKit_XX.X.X_Tool_expansion.zip”的扩容工具安装包。
    5. 登录SmartKit，单击“功能管理”。
    6. 单击“导入”，选择获取的扩容评估工具或扩容工具。

## 步骤：两台 Dorado 6800 V6 使用 SmartKit 扩容硬盘及存储池

**以下步骤1—8执行两遍：先完成MIT_YMS_ST1的全部步骤并验证通过，再对MIT_YMS_ST2执行步骤1—8。每次只操作一台设备。**

**步骤1 打开SmartKit并添加设备。**

在“设备列表”中单击“添加”，选择“指定IP地址”，按当前操作设备填写：

| 参数 | MIT_YMS_ST1 | MIT_YMS_ST2 |
|---|---|---|
| 管理IP | 10.254.17.116 | 10.254.17.118 |
| 设备SN | 2102354JLT10P2100002 | 2102354JLT10P2100001 |
| 机柜 | E12 | E13 |

单击“下一步”，输入超级管理员用户名`admin`和密码，单击“完成”。设备已添加时直接使用。

**步骤2 进入硬盘扩容工具。**

1. 选择“首页 > 扩容 > 扩容硬盘、硬盘框、硬盘柜”。
2. 单击“选择设备”，选择当前操作设备：**MIT_YMS_ST1（10.254.17.116）／MIT_YMS_ST2（10.254.17.118）**，设置该设备的结果保存路径，单击“确定”。
3. 单击“安全操作指引”，确认前置条件，勾选后单击“确认”。
4. 记录当前设备NAS池扩容前的总容量和未使用容量。

**步骤3 配置硬盘扩容评估。**

单击“扩容评估”，场景选择“扩容硬盘、硬盘框、硬盘柜”。接口卡、硬盘框部件编码留空，添加以下配置，两台填写相同：

![](_resources/%E5%8D%8E%E4%B8%BA%E6%9C%8D%E5%8A%A1%E5%99%A8/53672a2373e2c1a965100ea000492ba0_MD5.jpg)

| 存储空间扩容方式 | 硬盘BOM | 硬盘类型 | 单个硬盘物理容量 | 容量单位 | 硬盘数量 |
|---|---|---|---|---|---|
| 在CTE0上扩容存储池（ID:2） | 02355XJV | NVMe SSD（BOM自动带出） | 1.92 | TB | 6 |

单击“下一步”，确认提示，等待评估完成；通过后保存报告，单击“完成”。

**步骤4 安装新增硬盘。**

1. 单击“扩容”，选择“扩容硬盘”。
2. 核对新增硬盘为 **1.92TB NVMe SSD，BOM 02355XJV，每台6块**，按当前设备对应位置安装：

| 当前设备 | 机柜 | DAE000 | DAE020 |
|---|---|---|---|
| MIT_YMS_ST1 | E12 | 3U–4U，安装3块 | 6U–7U，安装3块 |
| MIT_YMS_ST2 | E13 | 3U–4U，安装3块 | 6U–7U，安装3块 |

3. 核对26–35号空槽，选定实际安装槽位并记录。佩戴防静电防护用品，完全打开硬盘拉手，对准槽位均匀推入，合上拉手，等待约15–30秒上电。
4. 确认运行指示灯绿色常亮、告警灯灭，新增6块硬盘均已识别、健康正常、运行在线。
5. 勾选“确认检查完成”，单击“确认”，完成硬盘扩容后的巡检并保存报告。

**步骤5 进入存储池扩容工具。**

返回首页，选择“扩容 > 更多 > 扩容硬盘域/存储池/性能层”。

单击“选择设备”，仍选择当前操作的 **MIT_YMS_ST1（10.254.17.116）／MIT_YMS_ST2（10.254.17.118）**，设置该设备的结果保存路径，单击“确定”。

**步骤6 配置NAS存储池扩容参数。**

单击“扩容评估”，场景选择“扩容硬盘域/存储池”，单击“添加扩容新硬件信息及存储空间扩容方式”。

参考上图，添加两行配置，两台填写相同：

| 存储空间扩容方式 | 硬盘框ID | 硬盘BOM | 硬盘类型 | 单个硬盘物理容量 | 容量单位 | 硬盘数量 |
|---|---|---|---|---|---|---|
| 在CTE0上扩容存储池（ID:2） | DAE000 | 02355XJV | NVMe SSD（BOM自动带出） | 1.92 | TB | 3 |
| 在CTE0上扩容存储池（ID:2） | DAE020 | 02355XJV | NVMe SSD（BOM自动带出） | 1.92 | TB | 3 |

核对目标为当前设备的 **NAS池（ID:2）**、合计6块，单击“下一步”。评估通过后保存报告，单击“完成”。

**步骤7 执行NAS存储池扩容。**

1. 单击“扩容”，选择“扩容存储池”。
2. 确认当前设备为 **MIT_YMS_ST1（10.254.17.116）／MIT_YMS_ST2（10.254.17.118）**，目标为NAS池（ID:2），新增硬盘6块。
3. 阅读注意事项，勾选确认项，单击“下一步”。
4. “扩容前检查”全部通过后，单击“下一步”，等待扩池完成；期间不做其他设备变更。
5. 显示扩容成功后，单击“下一步 > 完成”。

**步骤8 扩容后巡检与验证。**

单击“扩容后巡检”，完成检查并保存报告。登录当前设备的DeviceManager(默认端口8088)：

- **MIT_YMS_ST1：10.254.17.116:8088**
- **MIT_YMS_ST2：10.254.17.118:8088**

进入“系统 > 存储池”，确认：

| 检查项 | 预期结果 |
|---|---|
| 新增硬盘 | 6块均正常、在线 |
| NAS池 | 正常、在线，总容量较扩容前增加 |
| 业务及双活 | 无新增异常 |
| 告警 | 无新增与本次扩容相关的严重、重要告警 |

保存容量前后截图、报告及硬盘槽位、SN记录。

**MIT_YMS_ST1验证通过后，返回步骤1，对MIT_YMS_ST2执行同一套步骤；MIT_YMS_ST2验证通过后，两台6800扩容结束。**

## 步骤：OceanStor 6810 扩容硬盘框并新建NL-SAS存储池

本次在 **J13机柜19U–22U** 新增1个4U、24盘位SAS硬盘框，安装 **20块8TB NL-SAS硬盘**。使用SmartKit完成加框，再通过DeviceManager新建独立存储池，名称暂拟 **NLSAS_01**。原SAS池（ID:2）不扩容，原业务不会自动使用新池容量。

| 参数 | 本次填写值 |
|---|---|
| 设备名称 | p1opcst01 |
| 产品型号 | OceanStor 6810 |
| 管理IP | 10.254.130.48 |
| 设备SN | 2102354RTB10PC100001 |
| DeviceManager地址 | https://10.254.130.48:8088 |
| 新增硬盘框 | BOM 02352TKG，型号DAE62435U4，4U、24盘位，共1个 |
| 新增硬盘 | BOM 02352UPU，8TB、7.2K RPM、3.5英寸NL-SAS，共20块 |
| 新框级联端口 | CTE0.IOM.H6.P3、CTE0.IOM.L6.P3 |

> 本节为新建池方案草稿。实施前需确认客户接受独立池交付，并核实共享SSD性能层可提供新池所需配额。原20块1.8TB SAS扩池评估不作为本方案评估通过的依据。

**步骤1 添加设备并记录扩容前状态。**

1. 在SmartKit“设备列表”中单击“添加”，选择“指定IP地址”，输入 **10.254.130.48**，单击“下一步”；输入超级管理员用户名`admin`和密码，单击“完成”。已添加时直接使用。
2. 核对设备名称 **p1opcst01**、型号 **OceanStor 6810**、SN **2102354RTB10PC100001**。
3. 登录 **https://10.254.130.48:8088**，在“系统 > 存储池”记录现有SSD池、SAS池状态；打开“性能层”页签，核对共享性能层 **performanceLayer0（ID:0）** 的状态及可分配容量；在“系统 > 硬件”记录现有框及告警状态。

**步骤2 安装4U硬盘框与20块硬盘。**

1. 在 **J13机柜19U–22U** 定位安装位置，U位从机柜底部向上计数；安装一对滑道，保证前后左右水平并用M6螺钉固定。

![](_resources/华为服务器/6810_4U滑道安装.png)

2. **先装空框，再装硬盘**。由3人配合，将4U硬盘框沿滑道推入，用M6螺钉固定，检查框体水平、螺钉紧固。

![](_resources/华为服务器/6810_4U硬盘框上架.png)

3. 佩戴防静电防护用品，核对 **02352UPU、8TB NL-SAS、20块**；按面板槽位标识，本次安排 **0–19号槽位**，其余4槽保留假面板。完全打开拉手，对准槽位均匀推入，合上拉手，记录槽位与硬盘SN。
4. 此时**不连接新框电源**，先完成级联线缆连接。

**步骤3 连接新框级联线缆。**

采用笔记规划的 **H6/P3、L6/P3空闲端口新建环路**，两条mini SAS HD线缆分别粘贴两端标签，按下表连接：

| 线缆 | 控制框端 | 新增4U硬盘框端 |
|---|---|---|
| A侧链路 | CTE0.IOM.H6.P3 | 上方级联模块A的P0端口 |
| B侧链路 | CTE0.IOM.L6.P3 | 下方级联模块B的P0端口 |

以下为官方新建环路接线参考图。图中展示两个独立环路的示例，本次只新增 **1个框、2条线**，控制框端使用上表的 **P3**，不要照图增加第二个框或改用其他端口。新框A、B模块的P1端口本次不接线。

![](_resources/华为服务器/6810_新建环路接线参考.png)

连接后检查插头锁定、标签正确并整理线缆；保留现有硬盘框接线。新框仍不上电，等待SmartKit提示。

**步骤4 进入硬盘框扩容工具并配置评估。**

1. 在SmartKit选择“首页 > 扩容 > 扩容硬盘、硬盘框、硬盘柜”。
2. 单击“选择设备”，选择 **p1opcst01（10.254.130.48，SN 2102354RTB10PC100001）**，设置本台结果保存路径，单击“确定”。
3. 单击“安全操作指引”，确认准备项，勾选后单击“确认”。
4. 单击“扩容评估”，“扩容场景”选择“扩容硬盘、硬盘框、硬盘柜”，按下表填写：

![](_resources/华为服务器/6810_硬盘框扩容评估.png)

| 界面参数 | 填写值 |
|---|---|
| 新接口卡部件编码 | 留空，本次使用现有H6/L6级联模块 |
| 新硬盘框部件编码 | 02352TKG |

单击“添加扩容新硬件信息及存储空间扩容方式”，添加1行：

| 存储空间扩容方式 | 硬盘BOM | 硬盘类型 | 单个硬盘物理容量 | 容量单位 | 硬盘数量 |
|---|---|---|---|---|---|
| 新建存储池 | 02352UPU | NL-SAS（BOM自动带出） | 8 | TB | 20 |

5. 单击“下一步”，确认提示并等待评估完成；通过后保存报告，单击“完成”。

**步骤5 打开硬盘框扩容向导。**

1. 单击“扩容”，选择“扩容硬盘框”。
2. 阅读注意事项，勾选“我已完成上述注意事项的确认，并了解此操作带来的后果。”，单击“下一步”。
3. 等待“扩容前检查”全部通过，单击“下一步”，进入“配置硬盘框类型及数量”。
4. “所属控制框（控制器）”选择 **CTE0（0A/0B）**，“硬盘框数量”选择 **1**，单击“下一步”。如界面另列框类型，选择本次 **4U SAS硬盘框**。

![](_resources/华为服务器/6810_新增硬盘框数量.png)

**步骤6 按工具提示给新框上电并加入系统。**

1. 进入“连接线缆”页面后，再次核对 **H6.P3 → 新框A.P0、L6.P3 → 新框B.P0**，确认设备接地及供电条件。
2. 按工具提示连接新框两路电源至机柜对应的A、B路PDU，用卡扣固定电源线。上电过程中不插拔级联线或接口模块。
3. 检查框电源灯绿色常亮、框告警灯灭；硬盘运行灯绿色常亮、硬盘告警灯灭。
4. 勾选“我已完成上述注意事项的确认且完成上述操作，并了解此操作带来的后果。”，单击“下一步”。
5. 依次等待 **“新扩硬盘框加入系统”→“扩容后线缆检测”→“扩容后验证”** 完成，每页通过后单击“下一步”，最后单击“完成”。
6. 在DeviceManager“系统 > 硬件”确认新增1个4U框及20块8TB盘均正常、在线，记录新框实际ID。新框ID由系统识别，后续如需选框，以该ID为准。
7. 在SmartKit执行“扩容后巡检”，保存报告。

**步骤7 在DeviceManager创建新存储池。**

1. 登录 **https://10.254.130.48:8088**，核对 **p1opcst01、SN 2102354RTB10PC100001**。
2. 选择“系统 > 存储池”，单击 **“创建”**，不要选择原SAS池右侧的“扩容”。

![](_resources/华为服务器/6810_新建混闪存储池.png)

3. 按下表设置基本参数。图示来自产品文档，现网6.1.5不显示的高版本选项无需设置。

| 参数 | 本次填写内容 |
|---|---|
| 名称 | **NLSAS_01**（暂拟，实施前按客户命名规范确认） |
| 冗余策略 | **盘级冗余**；本次HDD仅来自1个新框，不选框级冗余 |
| 控制框 | **CTE0** |
| 容量层 | 选择 **NL-SAS、单盘8TB** 对应行，“需要硬盘数量”填 **20**；核对为步骤6记录的新框0–19号槽位 |
| 性能层 | 使用现有共享性能层 **performanceLayer0（ID:0）**，核对系统推荐配额及当前可分配容量 |
| 性能层共享策略 | 6.1.5默认共享，无此字段时无需填写；不新建独享性能层 |

> 新池由“NL-SAS容量层＋共享SSD性能层配额”组成。2026-10-20记录的performanceLayer0剩余容量为 **840.868GB**，仅是历史快照，不能据此认定足够。新池最小性能层配额由系统计算；不足时应先解决性能层容量或配额问题，再创建。若界面提示会自动将其他空闲SSD扩入共享性能层，须确认所涉硬盘，不将该操作视为本次默认动作。

**步骤8 设置高级参数并提交创建。**

1. 勾选右上角“高级”，按以下拟定值配置：

| 参数 | 本方案拟定值 |
|---|---|
| RAID策略 | **RAID 6**（官方默认策略） |
| 最大RAID成员盘数 | 保持系统默认 |
| 容量层热备策略 | **低（1盘）**，实施前确认此拟定值 |
| 数据加密 | 不新启用；核对与现有共享性能层加密属性一致，采集记录为Off |
| 容量告警阈值 | **80%** |
| 即将耗尽容量告警阈值 | **90%** |
| 其他参数 | 保持默认；不修改已有池配额或共享性能层RAID、热备策略 |

2. 核对 **NLSAS_01、CTE0、20块8TB NL-SAS、共享性能层及配额、RAID 6、热备策略**。
3. 单击“确定”，按界面提示确认，在“执行结果”页面等待任务成功。记录系统分配的新池ID，不能预填原SAS池ID 2。

**步骤9 创建后巡检与验证。**

1. 在DeviceManager“系统 > 存储池”检查新池，在“系统 > 硬件”检查新框和硬盘；在SmartKit对 **p1opcst01（10.254.130.48）** 执行巡检，保存报告。

| 新框及硬盘 | 新增1个4U框、20块8TB NL-SAS盘，均正常、在线 |
| 级联链路 | H6.P3、L6.P3均Link Up，无新增级联连线错误告警 |
| 新池NLSAS_01 | 正常、在线，容量层为本次20块NL-SAS盘，关联共享性能层；记录实际池ID、总容量及未使用容量 |
| 原SSD池、SAS池 | 状态正常，不以原SAS池容量增加作为验收要求 |
| 业务及告警 | 原业务正常，无新增与本次操作相关的严重、重要告警 |
